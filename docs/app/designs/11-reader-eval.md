# 11 对照评估：阅读 3.0 × 灵叙正文 + 其他可优化项

日期：2026-08-16。对照对象：legado-E / 阅读 3.0 的**阅读界面**，不学书源、订阅、净化。

## 1. 预设角色

旧 5 个（架构师 / 翻译 / 全栈 / 文档工程师 / 数据分析师）是助手人设，和灵叙「写网文」主路径无关。开局选角本来就不展示 builtin，设置里却把它们当模板，选中只能开一个程序员扮演会话。

新 7 个（5+2）：陆沉舟、谢无妄、沈昭宁、裴晏清、白蘅、顾晚棠、姜辞夜。覆盖都市重生、仙侠、古言嫡女、现言高冷、灵异、星际机甲、权谋反派。外貌 / 性格 / 背景写满，可直接「应用」成扮演会话。旧 builtin id 启动时删除。

仍刻意不做：开局主角池继续只显示用户自己的角色。预设是模板，不是把用户锁进这七张脸。

## 2. 阅读设置对照

阅读 3.0 正文自定义（README）：字体、颜色、背景、行距、段距、加粗、简繁；另有翻页（覆盖 / 仿真 / 滑动 / 滚动）。

| 能力 | 阅读 3.0 | 灵叙 0.2.5 | 取舍 |
|---|---|---|---|
| 日间 / 夜间 | 有 | 有 | 夜间暖墨，不跟应用深色强绑 |
| 背景色纸 | 有，可自定义图 | 素纸 / 羊皮 / 护眼 / 青灰 / 跟随 | 不做相册选图（权限 + 存图） |
| 字体 | 系统字体包 | 宋楷黑圆 + 系统 | 安卓缺字体时回落 |
| 字号 | 连续 | 13–32 | 取代底栏五档空转 |
| 行距 / 段距 / 字距 / 边距 | 有 | 有 | 只改正文，不改书架 |
| 加粗 | 有 | 有 | |
| 简繁 | 有 | 不做 | 要词库，写网文本体几乎都是简体 |
| 翻页模式 | 有 | 不做 | 灵叙是卷轴续写，不是翻页看书 |
| TTS / 亮度 / 仿真翻页 | 有 | 不做 | 非创作核心 |
| 入口 | 点屏出菜单 | 顶栏排版 + 底栏字体钮 | 安卓返回先关底栏 |

应用主题（书架 / 设置）仍走底栏日月钮。正文主题只活在 `DialogueNovel`。

## 3. 其他可优化项（按价值，本版未做）

**P1 体感**

- 点屏中部隐藏输入栏 / 功能栏，更接近阅读沉浸。现在只有下滑隐藏输入。
- 书内顶栏点书名进详情（改名、取名、导出、卷次）。
- 章节目录：用已有 `sceneAnalysis.chapterTitle` 跳到对应消息。
- 底栏功能钮在手机上过挤（模型 / 文风 / 思考 / 联网全堆一行），应收到「更多」。

**P1 内容一致**

- `character_cards` 与提示模板仍是程序员 / 产品经理。用户这次点名的是设置「角色」五预设；卡片库仍是另一套技术助手。
- 角色名册挂在书详情，压缩抽卡现在按 session，换书看不见。

**P2 作品层**

- 导出 EPUB / 封面页。
- 简繁、自定义背景图、亮度。
- 书级模型覆盖、每日字数目标、同世界再开一本（见 `10-later.md`）。

**P2 稳**

- 阅读排版按书记忆（现在是全局一份）。
- 场景分析失败时的可见重试，不只靠正文回落。
- 开局长指令对用户完全不可见，但失败时缺少「为什么没开篇」的一句人话。
