# 12 对照评估优化 · 开发计划（0.2.6）

日期：2026-08-16。来源：[11-reader-eval.md](./11-reader-eval.md)。

## Context

- 背景：阅读设置与网文角色已落地。评估里还列了一串书内体感、内容一致、稳定项。
- 目标：把清单里本圈该做的做完，打包装上。
- 范围：P1 全部 + P2 稳住 + 「同世界再开一本」。
- 不做（评估第 2 节已否，或仍属 10-later）：EPUB、简繁、自定义背景图、亮度、TTS、翻页、书级模型、每日字数。

## 验收标准

- [x] 点正文中部可收起输入栏和功能栏，再点展开；下滑逻辑仍在
- [x] 顶栏书名进入本书详情
- [x] 章节目录列出已出现章名，点击滚到对应段落
- [x] 窄屏底栏只留主操作，其余进「更多」
- [x] 角色卡 / 提示模板不再是程序员产品经理
- [x] 书详情能看到本书压缩抽出的角色
- [x] 换书会带上该书上次的阅读排版
- [x] 场景分析失败有一句原因和重试
- [x] 开局没发出去时，正文里有人话，可去设置
- [x] 详情可「同世界再开一本」，预填规则书与题材
- [x] `tsc --noEmit` 通过，版本 0.2.6

## 实施步骤

1. 正文沉浸：点屏收栏
2. 顶栏书名 → BookDetail；目录 sheet
3. FunctionBar 窄屏收进更多
4. 重建 character_cards、prompt_templates（upsert + 删旧 builtin）
5. 书详情角色名册 + 同世界再开一本
6. readerByStory 持久化
7. 场景失败重试、开局失败条
8. tsc、升版、提交、打 APK

## 风险

| 风险 | 应对 |
|---|---|
| 点屏与选字/操作钮冲突 | 忽略 button/textarea/选区 |
| 旧技术角色卡仍在库里 | 按新 id 列表删 isBuiltin 残余 |
| 开局失败被吃掉 pending | 清 pending 前先检查 blocker，失败写入 openingError |
