# 灵叙 APP 产品规格（书架时代）

> 分支：`APP`  
> 日期：2026-08-15  
> 状态：头脑风暴后的执行规格  
> 上级摘要：[`bookshelf-design.md`](./bookshelf-design.md)  
> 分块设计：[`designs/`](./designs/)  
> 回路：[`delivery-loop.md`](./delivery-loop.md)

本文把「书架 + 故事空间」从一页概念稿扩成可排队实现的产品。原则：**家是书架，书是故事，对话是书的内部，作品是导出层。** 学阅读的进出与管理，不学书源。

---

## 1. 用户要完成的事

装完灵叙的人不是来「开一个聊天窗口」的，是来 **写几本自己的故事，并且随时放下、换一本、再开一本、最后拿得出一篇字**。

| 任务 | 失败时的体感 |
|---|---|
| 今天接着写昨天那本 | 打开又掉进别的对话 / 找不到那本 |
| 换一个世界新开一本 | 找不到入口，或开了却把旧世界设定冲掉 |
| 写腻了退出去 | 返回键退出应用，像逃不出副本 |
| 整理成能给人看的字 | 只有带「请开始吧」和推荐条的聊天记录 |
| 管一堆半成品 | 会话列表像微信，不像书架 |

空白稿（日常改字、排版）也是「书」，只是分组叫稿纸，避免两套家。

---

## 2. 头脑风暴：功能池与取舍

从阅读书架、连载写作、本地创作工具三条线发散，再按「不抄书源、不重做引擎、服务多故事」收敛。

### 2.1 纳入（合理扩展）

**家与进出**

- 冷启动到书架；可选「打开时继续上次」（默认关）
- 继续阅读条（封面小图 + 书名 + 第几卷/最近章节）
- 书内明确「回书架」；安卓返回 = 回书架
- 新故事 / 稿纸 / 随机开一本：都在书架上，不藏进功能栏

**书的身份**

- 一本书 = 整条故事链（压缩续集是下一卷，不是新书）
- 状态：在写 / 搁置 / 完结
- 绑定：规则书、文风、主角名、题材、世界底座
- 主题封面（按底座配色 + 书名），可后换图
- 简介、标签、字数缓存、最近章节名

**书架管理（legado 骨架）**

- 网格 / 列表
- 分组 Tab：全部 · 在写 · 完结 · 稿纸（P2 再自定义书架）
- 搜索书名/主角/标签；排序：最近打开 / 最近更新 / 书名 / 创建
- 长按：继续、详情、重命名、置顶、完结、导出、删除
- 空态主按钮，有书时 FAB「+」

**书内**

- 顶栏：返回、书名（进详情）
- 卷次列表只含本书（旧卷只读，最新卷续写）
- 打开书时恢复：规则书、文风、上次卷
- 再入时顶上一条「上次写到：章节名」可点消失（不挡输入）

**开局**

- 入口只从书架来；取消回书架
- 完成时创建 Story + 首卷，写入绑定字段
- 保留现有 3 步开局 + 随机开局
- P1：最后一步可改书名；「同世界再开一本」预填规则书

**作品层**

- L1 干净 TXT：去开局指令、去模板标签、按章节/卷切分
- 默认「仅叙述」；可选「保留玩家行动」
- 另存文件，不覆盖对话
- L2 AI 整理、L3 EPUB：规格里写清，本回路不实现

### 2.2 明确不做（本产品阶段）

- 书源 / 发现网文 / RSS / 换源 / 缓存别人的书
- 社交、评论、排行、账号体系
- 多端实时同步（已有 WebDAV 备份即可，不围着书架再做一套云）
- 推送、每日提醒
- 底部四 Tab 一次到位（P0/P1 书架顶栏设置齿轮够用）
- 付费墙、会员
- 把 Session 模型推倒重写

### 2.3 三种产品形态（已选 C）

| 方案 | 内容 | 结论 |
|---|---|---|
| A 会话全屏化 | 会话弹窗变成一页 | 仍是聊天记录，否决 |
| B 纯聚合无表 | 用 chainId 当书 | 封面/分组/绑定无处放，否决 |
| C 故事实体 + 书架是家 | 新 `stories` 表 | **采用** |

## 4. 整条用户路径（验收剧本）

1. 新装 → 欢迎/配 API → **空书架**「写下第一个故事」
2. 走完开局 → 进入书内续写（不是再看不到书架）
3. 返回 / 安卓返回 → 书架上有一张书卡
4. 「+」再开第二个不同题材 → 书架两张卡
5. 点回第一本 → 规则书/文风/卷次是第一本的
6. 长按改名、置顶；继续阅读条能回到上次那本
7. 详情看到卷次；导出 TXT 不含 `【对话推荐】`
8. 压缩存记忆后书架仍是一张卡，副行卷号 +1

## 5. 共享约定（所有分块遵守）

- 桌面与 APP 同一套 IA，只调密度（手机网格 2 列，桌面 4–6 列或列表）。
- 实现写在 `APP` 分支；可原子 commit；不 push、不碰 `master`。
- `useChat` 不得只读全局 `activeBook`；以 `Story.worldBookId` 为准。
- 禁止自动 `createBlankSession` 占住空书架。
- 新 UI 不要塞进已 700+ 行的 `SessionPopup.tsx`。
- 安卓改前端必须重编 `.so` 才算真机更新（见根目录 `AGENTS.md`）。本回路验收以 `tsc` + 代码审查为准，不打包 APK。
- 备份：`settingsBackup` 增加 `stories` 组（随 `story-model` 或 `export-txt` 一起做，不要遗忘）。
