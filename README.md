# 灵叙 Narra（AIRP）

> AI Role Play — 沉浸式 AI 互动小说 / 角色扮演桌面客户端与安卓客户端

灵叙 Narra 是一款基于 **Tauri 2 + React 19** 的 AI 角色扮演应用，支持**桌面端（Windows）**与**安卓端**，两端共用同一代码库。你可以创建角色与世界书、设定世界观与规则、开启一场小说式的冒险，或使用空白会话进行日常 AI 对话。

## 功能亮点

- 🎭 **角色卡系统**：预设/自定义角色，支持 AI 对话式创建（与设定师对话自动生成角色设定）
- 🌍 **世界书系统**：关键词触发的世界观注入，防止 AI"出戏"，内置多主题预设（修仙/无限流/宫廷/规则怪谈等）
- 📖 **沉浸式开局**：选世界 → 选视角 → 选角色与开局场景，一键开始冒险
- 📝 **小说式排版**：AI 回复以小说章节呈现，场景条实时更新，对话推荐引导剧情
- 🔍 **联网搜索**：模型可调用实时搜索（DuckDuckGo/Bing/Serper 等），回答基于真实信息
- 🧠 **思考模式**：支持 DeepSeek 等模型的 reasoning 思考链路展示
- 💾 **数据管理**：本地 JSON 导出/导入（分组可选）、WebDAV 云端备份（按时间保留、内容选择导入）
- 🔐 **本地存储**：所有创作数据存于设备本地 SQLite，不强制上传任何服务器

## 构建与运行

### 桌面端（Windows）

```bash
npm install
npx tauri dev          # 开发模式
npx tauri build        # 打包（.msi/.exe）
```

### 安卓端

需要 Android SDK / NDK 与 Rust 的 `aarch64-linux-android` 目标（详见 `AIRP-移动端开发日志.md`）。

```bash
npx vite build
cargo build --release --target aarch64-linux-android   # 在 src-tauri 目录，设置 NDK 工具链环境变量
# 复制 libairp_desktop_lib.so 到 gen/android/app/src/main/jniLibs/arm64-v8a/
cd src-tauri/gen/android && ./gradlew assembleRelease
```
