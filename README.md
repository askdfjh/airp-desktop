# 灵叙 Narra

> 本地运行的文字创作与排版优化工具，支持桌面端（Windows）与移动端（安卓）。

灵叙 Narra 是一款基于 **Tauri 2 + React 19** 的本地工具，桌面端与移动端共用同一代码库。你可以创建与编辑各类设定、组织创作素材、以章节形式排版与呈现内容，也可使用空白会话进行日常文字处理与优化。

## 功能概览

- **角色设定管理**：预设/自定义设定，支持对话式生成与整理
- **背景设定库**：关键词触发的背景设定注入，内置多主题预设
- **创作引导**：选择题材与开局方向，一键开始
- **章节式排版**：内容以章节形式呈现，场景信息与建议实时更新
- **联网检索**：可接入实时检索（多引擎可选），补充时效信息
- **深度思考**：支持思考链路的展示
- **数据管理**：本地导出/导入（分组可选）、云端备份（按时间保留、内容选择导入）
- **本地存储**：所有数据存于设备本地，不强制上传任何服务器

## 构建与运行

### 桌面端（Windows）

```bash
npm install
npx tauri dev          # 开发模式
npx tauri build        # 打包（.msi/.exe）
```

### 移动端

需要 Android SDK / NDK 与 Rust 的 `aarch64-linux-android` 目标（详见开发日志）。

```bash
npx vite build
cargo build --release --target aarch64-linux-android   # 在 src-tauri 目录，设置 NDK 工具链环境变量
# 复制 libairp_desktop_lib.so 到 gen/android/app/src/main/jniLibs/arm64-v8a/
cd src-tauri/gen/android && ./gradlew assembleRelease
```
