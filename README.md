# 灵叙 Narra

> 本地运行的文字创作与排版工具。桌面端（Windows）与安卓端共用同一代码库。

当前产品主线在 **`APP` 分支**：打开就是书架，一本书就是一个故事。你可以随时放下、换一本、再开一本，最后把干净的正文导出去。空白稿纸（日常改字、排版）也是书架上的书，只是分组叫「稿纸」。

不提供书源、发现页、换源或阅读别人的网文。本软件是自己写、自己排、自己存。

本仓库：https://github.com/vdnight89/airp-desktop（分支 `APP`）  
上游原项目：https://github.com/askdfjh/airp-desktop

## 这一版（0.2.11）你能做什么

### 书架是家

- 冷启动进书架，不会自动跳进上一本对话，也不会偷偷建空白会话。
- 空书架有「写下第一个故事」；有书之后用右下角加号开新故事或稿纸。
- 分组：全部 / 在写 / 完结 / 稿纸。网格或列表。搜索书名、主角、标签。排序：最近打开 / 最近更新 / 书名 / 创建。置顶的书排在前面。
- 书卡带题材插画封面；右侧毛玻璃上竖排书名，长名折两列，不另铺笺纸底。
- 继续阅读条：封面小图 + 书名 + 卷次，一键回到上次那本。
- 长按或菜单：继续、详情、重命名、取书名、置顶、完结、导出、删除。
- 删除进回收站，可恢复或彻底清除；过期会自动清理。
- 安卓返回：先关详情 / 设置 / 开局上一步，再回书架；书架上再按一次才问是否退出。

### 开一本新故事

入口只在书架。取消回书架，中途退出不改已有书的规则书。

1. **选题材**：重生、穿越/穿书、系统流、末世、无限流、规则怪谈、经营/种田、民俗悬疑，以及男频升级/无敌/苟道/幕后/争霸/都市事业，女频娱乐圈/宅斗宫廷/情感婚恋/年代生活/事业成长/轻松日常/反内耗改命。卡片铺题材插画。
2. **选世界底座与文风**：现代、古代、修仙、未来、异世、无限；也可落到对应内置规则书。
3. **选主角**：内置网文向角色（陆沉舟、谢无妄、沈昭宁、裴晏清、白蘅、顾晚棠、姜辞夜），也可自建。
4. 点开始后创建 **故事 + 首卷**，绑定规则书、文风、主角、题材、世界底座，然后进入书内开篇。

另外：

- **同世界再开一本**：书详情预填规则书与题材，另起一本，不冲掉旧书。
- **随机开局**：书架加号里可直接开。
- 开篇发不出去时，正文里有人话提示，可去设置补模型。

### 书内书写

- 顶栏：回书架、点书名进本书详情、章节目录。
- 正文是小说排版，不是聊天气泡。点屏幕中部可收起输入栏和功能栏，再点展开。
- 场景条：地点、时间、出场、起因。
- **对话推荐**：点某一条即作为玩家行动发出，不必再按发送。正文生成中或推荐还在生成时不可点。
- 章节目录列出已出现的章名，点击滚到对应段落。
- 再入一本书时，顶上有「上次写到：章节名」，点一下消失。
- 窄屏底栏只留主操作，其余进「更多」。
- 功能栏：模型与服务、思考开关、文风预设、联网搜索、会话/卷次、世界信息、文字排版、阅读设置、整理记忆。
- **切书不串世界**：当前书只用这本书绑定的规则书，不会回落到上一本的激活书。
- 场景分析失败会显示原因，可重试。
- 长对话可压缩成续卷：旧卷只读锁定，新卷接着写，书架上仍是同一本书，卷号 +1。可从某条消息分支出去。
- 思考模型的思考过程可在规划指示里看见，完成后可回看。

### 阅读排版（只作用于书内）

独立于应用主题，并按书记住：

- 纸色：素纸 / 羊皮 / 护眼 / 青灰 / 跟随应用
- 夜间
- 字体：宋 / 楷 / 黑 / 圆 / 系统
- 字号、行距、段距、字距、页边距、加粗

### 书名

- 占位名（未命名稿纸、某某的冒险、扮演·角色）会在打开或回到书架时自动取名。
- 详情或菜单里可手动「取书名」。
- 优先问模型，只抠真正的书名（书名号、`书名：`、`叫作`、JSON）。思考模型吐出的推理句不会当书名。
- 模型没给可用名、没配模型、或超时：按题材和主角从本地书名库取一个封面式网文名，**不会再报取书名失败**。
- 已经中招的推理句书名，打开该书会自动换掉。

### 书详情

改名、简介、完结/继续写、删除、导出、取书名、同世界再开一本。能看到本书压缩抽出的角色名册。字数按正文重计。

### 导出作品

- 导出干净 TXT：去掉开局指令、模板标签、对话推荐。
- 默认只出叙述；可选保留玩家行动。
- 桌面走另存；安卓无保存框时复制或系统分享。不覆盖对话记录。

### 空白稿纸

日常改字、排版、闲聊。可单独打开「文字排版」：只做章节分隔，不注入规则书、角色卡、文风，也不触发压缩。

### 设定与能力

设置分栏：

| 栏 | 做什么 |
|---|---|
| 模型服务 | OpenAI 兼容接口（OpenAI / DeepSeek / Anthropic / Google / 月之暗面 / 通义 / 智谱 / OpenRouter 等）。多服务、选模型、思考模型、密钥只存在本机。提示词注入可按模型挂一段固定说明。 |
| 角色 | 预设与自建角色；对话里可生成、整理角色卡。书内压缩也会抽出角色。 |
| 规则书 | 内置：修仙、奇幻、都市、科幻、无限、娱乐圈、宫廷、言情、末世、民俗、规则怪谈、宅斗、年代、现代。可自建、关键词触发注入。每本书绑定自己的书。 |
| 输出预设 | 温度、篇幅、文风等生成参数。 |
| 插件 | 叙事防护、剧情推进、角色后台进展、随机世界事件、场景与推荐用的独立（可更快）模型。 |
| 外部工具 | 联网检索（多引擎）、MCP 服务。 |
| 数据管理 | 分组导出/导入 JSON；WebDAV 云备份（按时间保留、内容选择导入）；诊断导出不含密钥。 |
| 关于 | 版本说明、合规与风险、运行日志。 |

应用主题：浅色 / 深色 / 跟随系统。安卓上跟随系统会轮询补上 WebView 不派发主题变化的问题。

### 欢迎与第一次

未配置任何模型时先走欢迎页，可在应用内填接口。数据默认只在本机 SQLite。

## 构建与运行

### 桌面端（Windows）

```bash
npm install
npm run tauri:dev      # 开发
npm run tauri:build    # 打包 .msi / .exe
```

### 安卓端（重要）

**前端资源不是从 APK assets 加载的。** Tauri Android 的页面由 `generate_context!` 在编译期嵌入 `.so`。改前端后必须重新编译 `libairp_desktop_lib.so`，只复制 `assets` 不会更新真机上的界面。

完整流程在 `src-tauri` 目录（NDK 27、目标 `aarch64-linux-android`）：

```powershell
# 1. NDK 工具链
$ndk = "$env:LOCALAPPDATA\Android\Sdk\ndk\27.0.12077973\toolchains\llvm\prebuilt\windows-x86_64\bin"
$env:CC_aarch64_linux_android = "$ndk\aarch64-linux-android24-clang.cmd"
$env:AR_aarch64_linux_android = "$ndk\llvm-ar.exe"
$env:CARGO_TARGET_AARCH64_LINUX_ANDROID_LINKER = "$ndk\aarch64-linux-android24-clang.cmd"
$env:RANLIB_aarch64_linux_android = "$ndk\llvm-ranlib.exe"

# 2. 前端（会被编进 .so）
npm run build

# 3. Rust
cargo build --release --target aarch64-linux-android

# 4. 原生库必须就位，否则安装后闪退 UnsatisfiedLinkError
Copy-Item target\aarch64-linux-android\release\libairp_desktop_lib.so `
  gen\android\app\src\main\jniLibs\arm64-v8a\ -Force

# 5. 打包（本机若无 npm.bat，跳过 gradle 的 rust 任务）
cd gen\android
.\gradlew.bat clean assembleArm64Release `
  "-Pairp.android.allowDebugReleaseSigning=true" `
  -x rustBuildArm64Release -x rustBuildUniversalRelease
```

签名：正式 keystore 用环境变量 `AIRP_KEYSTORE_PASS` / `AIRP_KEYSTORE_ALIAS_PASS`。未设置时可加 `-Pairp.android.allowDebugReleaseSigning=true` 用 debug 签名。**debug 签名与正式签名不能互相覆盖安装。**

改 `tauri.conf.json`（如 CSP）后同样必须重编 Rust。jniLibs 更新后 gradle 增量可能漏拷，用 `clean` 或 `--rerun-tasks`。

闭环自测（不启 UI）：

```bash
node scripts/test-core.mjs
npx tsc --noEmit
```
